Heisser als der Hitzesommer

Von der Messstation bis zur Grafik: So fliessen die Daten des Bundesamts für Umwelt durch unser Projekt.

im3.ixigamil.myhostpoint.ch
  1. 01

    BAFU-API

    data.bafu.admin.ch/api · GraphQL
    • Hydrologische Beobachtungen des Bundes, offene Daten
    • Tagesmittel Wassertemperatur und Wasserstand
    • 6 Messstationen: 3 im Mittelland, 3 in den Alpen
    6Stationen, seit 2020
  2. 02

    Extract

    etl/extract.php · fetchJson() mit cURL
    • GraphQL-Abfrage per POST, jeden Tag per Cronjob
    • Max. 10 000 Zeilen pro Abfrage → Zeitfenster, bei Bedarf halbiert
    • Bei Ausfall: 3 Wiederholungen (2 · 4 · 8 s), dann Protokoll
    2Requests pro Tag
  3. 03

    Transform

    etl/transform.php
    • Einheit prüfen (°C, m ü.M.), Werte auf Plausibilität
    • Zeitstempel UTC → Kalendertag in Schweizer Normalzeit
    • Nichts wird geschätzt: Sensorausfälle werden verworfen
    3Werte verworfen
  4. 04

    Load

    etl/load.php · PDO · Prepared Statements
    • INSERT … ON DUPLICATE KEY UPDATE: neu, geändert oder gleich
    • Die letzten 60 Tage werden neu geladen: Das BAFU prüft nachträglich
    • Jeder Lauf wird in import_runs protokolliert
    0Duplikate
  5. 05

    MySQL-Datenbank

    Hostpoint · eigene Datenbank · etl/schema.sql
    • Die einzige Datenquelle für die Website
    • UNIQUE (Station, Messgrösse, Zeitpunkt) verhindert Doppelte
    • Fällt die BAFU-API aus, bleiben die Daten verfügbar
    29 541Messwerte · 28.09.2026
  6. 06

    Unload

    unload.php → JSON nach Datenvertrag v1
    • Liest nur aus MySQL, nie aus der BAFU-API
    • Filter: stations · parameter · years · from · to
    • Wasserstand als Abweichung vom mittleren Pegel in cm
    7Felder pro Datensatz
  7. 07

    DataStory

    index.html · script.js (fetch + D3.js) · style.css
    • Temperatur-Streifen, Kennzahlen, Jahr gegen Jahr, Urteil
    • Alle Zahlen im Text werden live aus den Daten berechnet
    • Desktop und Mobile, Tooltips, Vollbild, Filter
    2022vs. 2026

Warum eine eigene Datenbank?

Die Website hängt nie direkt an der BAFU-API. Ist die API offline, zeigt die Seite weiter die gespeicherten Daten, und der nächste Import holt alles nach.
